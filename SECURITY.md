# Security Policy

## Supported Versions

Security updates are provided for the latest published release of each
`@aziontech/*` package in this repository. Please make sure you are running the
most recent version before reporting an issue.


## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via [GitHub Security Advisories](https://github.com/aziontech/lib/security/advisories/new):

1. Go to the **Security** tab of this repository
2. Click **Report a vulnerability**
3. Fill out the vulnerability report form

Alternatively, you can email the Azion Security team at security@azion.com.

Please include as much detail as possible:

- A description of the vulnerability and its impact.
- Steps to reproduce (proof of concept, affected version, environment).
- Any suggested remediation, if known.

## Disclosure Timeline

We will acknowledge your report within 3 business days and aim to provide a
resolution or mitigation timeline within 10 business days. We ask that you keep
reports confidential until a fix has been released.
